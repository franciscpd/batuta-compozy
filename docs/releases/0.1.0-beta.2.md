# Batuta v0.1.0-beta.2 preview

`v0.1.0-beta.2` is the reviewed preview release of Batuta from
`franciscpd/batuta-compozy`.

## Verified scope

This preview packages exactly one `batuta` agent, one `batuta-routing` skill,
and one `batuta-deliver` Loop. Batuta is verified as resource-only
orchestration: it classifies, decomposes, dispatches, and reports, but does not
write implementation code. It was verified against CompozyOS
`v0.3.0-beta.16-9-ga35eda6d` at full commit
`a35eda6d3a2ec47995c19a14a5a01d4f9452cf1c`, or a later release that contains
it.

## Known upstream limitations

These are CompozyOS limitations, not Batuta fixes: executor sessions are not
visually nested and remain active/idle after normal terminal completion. This
preview does not claim either limitation is fixed or that executor sessions
stop automatically.

## Install the preview

The release assets are exactly `batuta-compozy_0.1.0-beta.2.tar.gz` and
`SHA256SUMS`. Download both from the release, verify the checksum, then extract
into a new directory and validate it:

```bash
preview_dir=$(mktemp -d)
gh release download v0.1.0-beta.2 --repo franciscpd/batuta-compozy --dir "$preview_dir"
(cd "$preview_dir" && sha256sum --check SHA256SUMS)
extracted_directory=$(mktemp -d)
tar -xzf "$preview_dir/batuta-compozy_0.1.0-beta.2.tar.gz" -C "$extracted_directory"
compozy extension validate "$extracted_directory" -o json
```

Installing this preview crosses an explicit trust boundary. Only if you accept
the unverified preview source, install the validated extracted directory:

```bash
compozy extension install "$extracted_directory" --allow-unverified --yes
```

To remove this preview or roll back before installing a different validated
package:

```bash
compozy extension remove batuta --global
```
